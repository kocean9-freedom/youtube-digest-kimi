# Bilibili Digest 首版设计

用户于 2026-10-08 确认首版范围，并授权完成、测试、推送到其现有仓库，显著注明二创来源。后续实施由本会话自主完成。

## 用途与交付

在 `bilibili-digest/` 提供独立 Chrome Manifest V3 扩展，最低 Chrome 116。普通 BV 视频、当前分 P 的已有字幕可搜索、跳转、复制、导出 Markdown/TXT/SRT；字幕提取无需 Supadata 或 AI Key。中文侧边栏提供主动触发的 AI 概览、翻译、片段讲解和本地笔记。导出供 Codex 阅读，首版不自动投递到 Codex。

## 边界和复用

保留根目录 YouTube 扩展；B 站版复用并署名现有 `settings.js` 与 `ai-providers.js` 协议实现，单独存储设置，不迁移或读取已有扩展凭据。原 Zara Zhang MIT LICENSE 原文保留；README、THIRD_PARTY_NOTICES 和界面链接注明原仓库及本仓库衍生关系。本次不下载视频、不做音频转录/OCR，不覆盖番剧/直播/课程/互动视频或整合集批量任务。

## 数据流

1. 内容脚本只在 `https://www.bilibili.com/video/*` 运行，通过当前 URL 和公开视频元数据识别 BV、P 和 cid。API 请求使用浏览器管理的登录会话，不访问 Cookie API、不读取 document.cookie、不持久化凭据。
2. 内容脚本获取站方字幕列表；后台只下载白名单 HTTPS hdslb.com 字幕 JSON，禁用重定向和凭据，不接受页面传来的任意网络 URL。
3. 字幕统一为 `{start,end,text}`，缓存、笔记、AI 结果以 BV/cid 区分。页面切换或分 P 变化立即清空旧内容，迟到请求不得写入新视频。
4. AI 请求仅由扩展侧边栏/设置页触发，按已选提供商的准确来源检查权限。每批请求一次，不自动重试/回退；响应有限长和超时，错误不暴露服务商自由正文或凭据。
5. API Key 只存 trusted Chrome storage；页面脚本不能调用 AI 或读取设置/笔记。字幕数据当作不可信来源，显示使用 textContent，AI 提示明确不执行字幕中的指令。

## 交互和异常

中文纸张式侧边栏，字幕/概览/笔记三个视图。字幕语言选择、关键词匹配数量、带时间戳的字幕段、复制和导出始终不依赖模型。自动识别当前视频，允许手动刷新；选中片段可保存原文笔记或讲解。AI 翻译按小批次对齐段 ID；失败保留原文和已完成批次，并明确提示。超长字幕摘要分块后综合，标示预计请求数。取消或换视频后不再追加后续请求；已经发送的请求可能仍收费。

空字幕、需要登录、网络/接口风控、扩展重载后页面未刷新分别给出可操作中文说明，不把弹幕当字幕。导出含标题、UP 主、BV、cid、P、原始链接、时间戳和字幕来源；笔记可导出 Markdown。无 Key 时禁用 AI 但保留字幕功能。
