# 数据流向与本地存储

本版本供个人使用，没有插件账号、广告、分析统计、遥测或开发者服务器。

## B 站字幕

- 内容脚本仅在 B 站普通视频页面运行，读取公开视频元信息及当前 BV/分 P。
- 字幕列表请求由浏览器自动使用站点现有登录会话。扩展不访问 Cookie API，不读取 `document.cookie`，不导出或记录账号凭据。
- 字幕正文只从经过校验的 HTTPS `hdslb.com` 子域的字幕路径获取，下载不携带凭据且不跟随重定向。
- 字幕获取仍会经过 B 站及其 CDN，这些服务按照自身政策处理请求。

## AI 服务

- 只有主动点击概览、翻译、讲解、润色或测试连接时才发送模型请求。
- 概览发送视频标题与字幕段；翻译发送当前批次字幕；讲解发送选中片段和相邻上下文；润色发送你填写的笔记。测试只发送短文本。
- 请求直接发送给当前选择的服务商。使用 OpenRouter 时，内容也可能被交给所选模型的托管方。
- Key 仅用于当前服务商的请求身份验证。不同提供商独立存储，按准确来源核对 Chrome 权限，不自动跨服务商回退。
- 网络请求和字幕显示都是不可信输入；服务商自由错误正文不显示、不记录。页面脚本不能通过扩展消息读取 Key 或触发 AI 请求。

## 本地数据

- Key、配置、字幕缓存、模型结果和笔记存放在 `chrome.storage.local`，访问限制为扩展可信上下文。
- 本版本与 YouTube 版为不同扩展，存储各自独立，不自动读取或复制 YouTube 版 Key。
- 本地存储不是加密保险箱；能访问你的浏览器或电脑的其他主体仍可能读取数据。不要把浏览器配置或存储备份公开。
- 卸载扩展会删除其本地数据；笔记请提前导出。删除某服务商 Key 可在设置页点击“删除此 Key”，可选网址权限可在 Chrome 中撤销。
- 导出文件和复制内容由你自行决定保存/分享到哪里，包括交给 Codex 分析。分享前请检查其中是否包含私密内容。
